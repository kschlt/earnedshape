# Shared Language Research — Protocol Implications

> **Sources** for the research claims below are listed in [`REFERENCES.md`](REFERENCES.md), with a table of which claim rests on which study. Two claims here are weaker than they read — the effect of labels on attention, and LLM reformulation revealing implicit content — and two are protocol inferences rather than findings (candidate terms as semantic probes; the failure-mode list); see [the notes there](REFERENCES.md#where-the-support-is-thinner-than-the-wording).

## Decision

Shared Conceptual Language should enter Protocol v0.2 as a **first-class cross-cutting concern**, but not as:

- a sixth Human Contribution;
- a heavy glossary discipline;
- a separate terminology phase;
- a human-first naming mandate.

## Core refinement

Original tentative hypothesis:

> Meaning before naming.

Research-supported refinement:

> **Meaning before commitment.**

Early names can:
- improve articulation;
- expose distinctions;
- help memory;
- introduce useful domain vocabulary.

The risk is not early naming itself.

The risk is:

```text
fuzzy human input
→ AI interpretation
→ polished AI term
→ repeated use
→ implicit conceptual commitment
```

## Strongest practical rule

> **A model-bearing AI term should initially be treated as a proposal, not as proof that the concept has been mutually understood and accepted.**

## Shared-language behavior

Recommended default for significant concepts:

```text
reflect source meaning
→ clarify only consequential ambiguity
→ offer candidate language
→ expose model implications
→ use a working term
→ test meaning in concrete use
→ stabilize selectively as canonical-for-now
→ reopen when the model changes
```

## Why this matters specifically with AI

Relevant evidence families indicate:

- humans naturally converge lexically with conversation partners;
- humans can align strongly with computer/agent language;
- labels can influence categorization and attention;
- LLM suggestions can affect later human expression, ideation and reported attitudes;
- early LLM involvement can reduce independent ideation/ownership in some tasks;
- LLM reformulation can also improve articulation and reveal implicit content.

Therefore the correct goal is **calibrated co-construction**, not AI silence.

## Candidate terminology as semantic probe

A useful new synthesis is:

> Candidate terms can function as semantic probes.

For example:

- `State`
- `Memory`
- `Ledger`

may reveal different assumptions about:
- persistence;
- source of truth;
- forgetting;
- traceability;
- mutability.

Use terminology comparison to expose models, not to run a naming contest.

## Lightweight state

Only model-relevant concepts need explicit entries.

Candidate fields:
- current term;
- meaning;
- status;
- context;
- source expression when useful;
- example/boundary;
- optional provenance;
- open issue;
- meaningful rename history.

## Main failure modes

- AI terminology anchoring
- false shared understanding
- lexical alignment without conceptual alignment
- premature canonicalization
- false precision
- source erasure
- semantic drift
- jargon inflation
- context collision
- vocabulary bureaucracy
- suppression of useful ambiguity

## Experimental questions

Still unknown:

- actual effect size of AI terminology anchoring in long discovery;
- optimal delay between human articulation and AI terminology;
- value/cost of preserving source language;
- whether explicit candidate labels change behavior;
- whether scenario testing pays for its interaction cost;
- whether visible origin/provenance helps or biases;
- whether lightweight concept state beats strong implicit memory.

These should remain learning hypotheses.
